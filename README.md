# Mini Bot — نسخه وب (ظاهر جدید هماهنگ با سایت)

نسخه: v12.2.6 (restyle blue) — همان پنل قبلی با تمام امکانات، فقط ظاهرش
با هویت بصری سایت رسمی هماهنگ شده است: آبی برند #196FF0، پس‌زمینه
روشن خنثی، سایه‌های آبی ملایم و آیکن‌های شیک lucide.

هیچ منطق یا قابلیتی تغییر نکرده است؛ فقط رنگ‌ها و متغیرهای تم.

## ساختار

- `public/index.html` — نسخه وب کامل (تک‌فایل)
- `worker.js` — پروکسی Cloudflare Worker (بدون تغییر)
- `wrangler.jsonc` — کانفیگ دیپلوی (بدون تغییر)

## تغییر آدرس سرور

آدرس سرور ربات در متغیر `UPSTREAM` در ابتدای `worker.js` است؛ برای هر
سرور دیگر فقط همان یک خط عوض می‌شود.

## دیپلوی

مخزن را در داشبورد Cloudflare (Workers & Pages) وصل کنید؛ `npx wrangler deploy` همین کانفیگ را می‌خواند.

## تم تیره

تم تیره هم به همین آبی هماهنگ شده؛ سوییچ تم همان قبلی است.
