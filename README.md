# Mini Bot — پنل کاربران (نسخه وب)

پنل کاربران Mini Bot؛ کاربر با نام کاربری و رمز وارد می‌شود و داشبورد، فیش‌ها، پلن، قابلیت‌ها و تنظیمات را می‌بیند.

نسخه: v12.2.6 (restyle blue) — وضعیت: تولیدی، روی Cloudflare Workers

## نمای کلی

- یک فایل HTML کامل بدون مرحله build؛ همه‌ی استایل و اسکریپت داخل `public/index.html` است.
- `worker.js` نقش پروکسی دارد: هر مسیر `/api/*` به سرور ربات می‌رود و بقیه به فایل‌های استاتیک.
- پشتیبانی چند-سروری: کلاینت هدر `x-server` می‌فرستد و Worker درخواست را به همان سرور می‌فرستد.
- هویت بصری هم‌رنگ سایت: آبی برند `#196FF0`، پس‌زمینه روشن، آیکن‌های lucide، تم روشن و تیره.

## ساختار فایل‌ها

```
public/index.html   پنل کامل (تک‌فایل)
public/app.js       منطق کلاینت
public/style.css    استایل و متغیرهای تم
public/icon-192.png آیکن PWA
worker.js           پروکسی Cloudflare + رجیستری سرورها
wrangler.jsonc      کانفیگ دیپلوی
```

## تنظیمات کلیدی

| مقدار | جای تغییر | توضیح |
| --- | --- | --- |
| `UPSTREAM` | ابتدای `worker.js` | سرور اصلی و نگهدارنده‌ی لیست سرورها |
| `x-server` | کلاینت | شناسه‌ی سرور انتخاب‌شده در صفحه ورود |
| `BASE_URL` | `public/index.html` | خالی و نسبی؛ دست نزنید |

- لیست سرورها از `/api/servers` گرفته و ۶۰ ثانیه کش می‌شود؛ اگر سرور اصلی جواب نداد، از همان کش استفاده می‌شود.
- مسیرهای `/api/servers` و `/api/admin/servers` همیشه به سرور اصلی می‌روند، حتی اگر کاربر سرور دیگری انتخاب کرده باشد.
- پاسخ‌های HTML با `Cache-Control: no-store` سرو می‌شوند تا بعد از دیپلوی نسخه‌ی قدیمی نماند.

## تب‌های پنل

1. `dashboard` — وضعیت اتصال، آمار، لینک جفت‌سازی
2. `exchange` — فیش‌ها، گروه‌های مجاز، تأیید پرداخت
3. `features` — پلن، درخواست اشتراک، قابلیت‌های فعال
4. `profile` — نام کاربری، رمز، آواتار، خروج

## دیپلوی

مخزن را در داشبورد Cloudflare به Workers & Pages وصل کنید، یا:

```
npx wrangler deploy
```

سپس از تب Domains دامنه‌ی `web.minibot.online` را به Worker اضافه کنید.

> هر push روی `main` باعث دیپلوی مجدد همین Worker می‌شود (چند ثانیه و بدون قطعی). سرور ربات روی Render دست نمی‌خورد.

## مخزن‌های مرتبط

1. `minibot` — کد سرور ربات (نسخه‌ی هماهنگ: v12.2.6)
2. `minibot-admin` — پنل مدیریت
3. `minibot-site` — سایت معرفی
4. `minibot-quick` — اپ سریع مدیریت
